# Contributing to Mood Mirror Tarot

Thank you for considering contributing! Whether it's a bug report, feature idea, or a pull request — all contributions are welcome.

## 🐛 Reporting Bugs

1. Search [existing issues](https://github.com/xuelei321/vibe-taluo/issues) first
2. Use the Bug Report template when creating a new issue
3. Include your browser version, OS, and steps to reproduce

## 💡 Feature Requests

1. Check existing issues for similar ideas
2. Use the Feature Request template
3. Explain the use case and why it would benefit the project

## 🔧 Pull Requests

1. Fork the repository
2. Create a feature branch: `git checkout -b feat/my-feature`
3. Commit with conventional commits:
   - `feat:` — new feature
   - `fix:` — bug fix
   - `docs:` — documentation
   - `style:` — formatting
   - `refactor:` — code restructuring
   - `perf:` — performance
4. Run `npm run build` before submitting
5. Open a PR against the `main` branch

## 🧪 Development Setup

```bash
git clone https://github.com/xuelei321/vibe-taluo.git
cd vibe-taluo
npm install
npm run dev
```

## 📐 Code Style

- TypeScript strict mode is enabled
- Vue 3 `<script setup>` composition API
- Tailwind CSS for styling, custom CSS only for complex animations
- Composables live in `src/composables/`, grouped by domain
